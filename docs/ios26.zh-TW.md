# iOS 26 在 OnePlus 6T（除錯版，進行中）

[English](ios26.md)

> [!WARNING]
> **這是開發中的除錯版，不是給一般人用的 Beta。** 沒有安裝包、沒有 `setup.sh`；只能從 Mac 以 RAM 開機測試。
> 想日常使用請用 [iOS 16.5 的 Beta 0.8.1](../releases/v0.8.1-beta.md)。

iOS **26.5.2**（23F84，iPhone 11 的 IPSW）跑在同一套開源 XNU 上：核心換成 xnu-12377.121.6，6T 全部驅動搬過去。
原始碼在 [hakios-xnu-kernel 的 `ios26` 分支](https://github.com/kiwiiiii-eth/hakios-xnu-kernel/tree/ios26)。

## 跟 16.5 最大的差別

| | iOS 16.5 | iOS 26 |
|---|---|---|
| 畫面合成 | QuartzCore 自己支援 OpenGL ES | 只剩 Metal；我們把繪圖器換回它還留著的 OpenGL ES 那套 |
| 系統程式 | 照原樣執行 | arm64e 指令要先改寫（自寫 `pac_lower`），系統 cache 約 2,900 萬條 |
| Wi‑Fi 介面 | IO80211 舊格式 | 掃描、連線、事件結構都變大，逐一對過 |
